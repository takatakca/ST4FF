## Notes de production

- Utiliser uniquement les employés et numéros fictifs en 555 à l'écran.
- Ne montrer aucun renseignement réel d'employé ni aucun numéro de carte : données sandbox seulement.
- Montrer l'application réelle (prototype ou version sandbox) : l'équipe de révision doit voir la construction d'un horaire, un pointage sur l'appareil, un refus d'entrée hâtive et le rapport ventes vs main-d'œuvre.
- Garder chaque plan lisible au moins 3 secondes pour les écrans avec du texte.
- Le code d'employé saisi à la scène 4 doit être celui d'un employé fictif du marchand sandbox ; ne jamais filmer un vrai code.
